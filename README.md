# SellLemonsScript
Simple Clean Easy To Use Script For The Game On Roblox Named Sell Lemons.

### Clean Ui Simple UI.

# Features: 
Auto Farm (Customizable/Has Settings)
Auto Income (Customizable/Has Settings)
Auto Upgrade (Customizable/Has Settings)
Auto Buy Tycoon Upgrades
Auto Fruit
Auto CashDrop
Auto Accept Phone Offer
Auto Rebirth
Auto Evolve
Auto Power Level
